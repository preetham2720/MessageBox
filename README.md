# Message

A simple web application that allows users to type a message in a textarea while enforcing a maximum of 200 characters. The app displays a live character counter and shows an error message when the limit is exceeded.

## Features

- Text area for entering a message
- Live character count display
- Maximum limit of 200 characters
- Error message when user tries to exceed the limit
- Responsive and centered layout
- Modern dark-themed UI

## Tech Stack

- HTML5
- CSS
- JavaScript
- Tailwind CSS
- Google Fonts
- Font Awesome
